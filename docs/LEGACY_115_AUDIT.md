# 115 旧数据审计提醒（2008–2025）

## 背景

`/GAL/GAL-YYYY` 中存在大量 2008–2025 年的旧目录。这些目录可能来自：

- 旧 Getchu 流程自动提交
- 手动上传到 115 的内容
- 历史整理结果
- 已经失效或重复的目录

因此**不能把旧年份目录默认当成无主数据，更不能批量删除**。

## 已知案例

2026-01 曾发现两个旧格式目录，EGS 新流程没有引用：

```text
[2026-01-30][FuriKuru]諦観のイヴ・べセル
[2026-01-30][Miel]美姫クローディアは孕ませオナホ～高潔な姫がチン負け屈服、王位も遺伝子も差し出し媚びアクメ！～
```

其中第一条与 EGS 新目录并存；第二条在 EGS 新库中没有对应记录。  
这两个已于 2026-09-05 手动删除。

## 后续执行原则

1. **不要对 2008–2025 年做自动删除。**
2. 对旧年份执行整理前，先跑只读审计：
   - 列出 `/GAL/GAL-YYYY` 实际目录；
   - 与 `egs_115_folders` 中该年份记录比对；
   - 可选再与 `getchu.db` 旧状态记录比对；
   - 输出未引用目录清单，不修改 115。
3. 对疑似无主目录，先人工确认：
   - 是否有对应 Getchu 记录；
   - 是否有对应 EGS 记录；
   - 是否可能是手动上传内容；
   - 是否存在同名/近名、复刻、重发、DLC、特典目录。
4. 只有明确确认废弃后，才允许手动删除。

## 建议后续任务

写一个 `legacy_115_audit` 类功能：

```text
输入年份范围
输出：
- 年份目录清单
- EGS 已引用目录
- 旧 Getchu 疑似引用目录
- 完全未引用目录
- 冲突/同名/近名目录
```

该功能第一阶段只做报告，不重命名、不移动、不删除。  
后续如果确认可以清理，再单独提供白名单式手动执行。
