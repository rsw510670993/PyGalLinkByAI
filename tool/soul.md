# Nyaa 匹配约束

## 发布来源偏好
- girlcelly 和 2D.G.F. 是两大游戏下载链接发布来源。
- 当多个候选分别来自 girlcelly 和 2D.G.F. 时，优先选择 girlcelly，其次选择 2D.G.F.。
- girlcelly 和 2D.G.F. 是发布来源标记，**不是排除、弃置或重复要素**。

## 判定原则
- matched：候选与 Getchu 游戏本体一致。
- unmatched：没有候选匹配。
- duplicate：候选是同一资源的重复发布。
- discarded：候选不是游戏本体，例如廉价版、OST、补丁、特典等。
- review：无法确定，需要人工复核。

## 关键字记忆
- 可以提炼可复用关键字，例如“廉价版”→discard、“DL版”→include。
- 不要将发布来源标记 girlcelly / 2D.G.F. 提炼为 discard / duplicate / review。
